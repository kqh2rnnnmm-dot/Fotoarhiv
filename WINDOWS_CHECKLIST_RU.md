# Проверка Фотоархива 0.2.1 на Windows 11 x64 — без терминала

Статус этого документа: план проверки, НЕ доказательство её выполнения.
В этой поставке нет проверенного Windows ZIP. P0 остаётся открытым.

## Как получить проверяемую сборку (5 действий)

1. Распакуйте полный исходный ZIP. Владелец репозитория переносит его содержимое через GitHub Desktop
   в main/master репозитория https://github.com/kqh2rnnnmm-dot/Fotoarhiv , сохраняя `.github/workflows`. Подключение ChatGPT только для чтения этого не делает.
2. Во вкладке **Actions** откройте **Build Fotoarhiv Windows x64**. При необходимости нажмите
   **Run workflow**. Дождитесь результата. При ошибке скачайте `Fotoarhiv-Windows-test-results`
   и передайте журнал для исправления. Ошибку нельзя считать успешной сборкой.
3. При успехе скачайте **Fotoarhiv-Windows-x64-0.2.1-TEST** и **Fotoarhiv-Windows-test-results**.
   В первом артефакте распакуйте вложенный `Fotoarhiv_Windows_x64_TEST.zip` в отдельную папку.
   Сохраните все DLL и другие файлы вместе с `Fotoarhiv.exe`.
4. Дважды щёлкните `Fotoarhiv.exe` на Windows 11 x64. Отдельная установка .NET не требуется.
   Если защита Windows блокирует запуск, зафиксируйте сообщение и остановите проверку;
   не отключайте защиту и не добавляйте исключения.
5. Выполните сценарии ниже на искусственном наборе `tests/manual_samples` из исходного ZIP.
   Не выбирайте личные коллекции для первой проверки. Сохраните снимки окна и заполненные результаты.

## Что отмечать

У каждой строки укажите PASS / FAIL / NOT RUN, дату, версию Windows из **Параметры → Система → О системе**,
ссылку/номер Actions run и имя снимка окна. Отсутствие ошибки в журнале не заменяет наблюдение результата.
Автоматизация в CI проверяет часть сценариев. Физический диск и пользовательский ПК проверяются отдельно.

| Проверка | Действия и ожидаемый результат | Результат |
|---|---|---|
| Первый запуск | В новом профиле Windows откройте программу: пустая библиотека, страница 1/1. Не удаляйте существующий каталог ради теста | NOT RUN |
| Два источника и подпапки | Добавьте Source_A, затем Source_B из manual_samples: 80 фотографий, Nested включена; источники видны в разделе «Источники» | NOT RUN |
| Поиск | Введите capture-2020: один результат; очистите поле: снова 80 | NOT RUN |
| Фильтр года | Выберите 2020: два снимка с EXIF; верните «Все годы». Если распаковка дала BMP тот же год, отдельно учитывайте файловую дату | NOT RUN |
| Страницы и карточка | Перейдите стрелкой на 2/2 и обратно; щёлкните capture-2020.jpg: сведения и источник даты EXIF | NOT RUN |
| Дата без EXIF | У BMP показана «Дата файла», а не EXIF; дата соответствует свойствам файла в Проводнике | NOT RUN |
| GPS и предупреждение | В «Места съёмки» есть только synthetic-gps.tiff; текст предупреждает о передаче координат OpenStreetMap. До нажатия карта не открывается | NOT RUN |
| Карта по действию | Только если согласны передать искусственные координаты сервису: выберите тестовый TIFF и нажмите открытие точки; браузер показывает соответствующую точку | NOT RUN |
| Точные повторы | Одна группа: identical-a.bmp и identical-b.bmp; same-size-different.bmp исключён | NOT RUN |
| Отмена | На достаточно большом искусственном наборе нажмите «Обновить», затем «Остановить» до завершения. Нужна надпись об остановке, а не «Готово» | NOT RUN |
| Повторный запуск | Закройте окно и откройте снова: 80 записей, источники сохранены. Для нового поиска групп нажмите «Обновить» | NOT RUN |
| Отключённый диск | При наличии отдельного тестового USB-диска с искусственными изображениями добавьте его, закройте программу, безопасно извлеките диск через Windows и снова откройте программу: записи остаются, источник недоступен | NOT RUN |
| Физическое отключение | Если отдельного диска нет, оставьте NOT RUN. Имитация недоступного пути в xUnit — другая проверка | NOT RUN |
| Ошибка чтения | В тестовом окружении разработчик блокирует чтение искусственного файла; программа продолжает работу и показывает неполную проверку. Не меняйте права на личных фотографиях | NOT RUN |
| Оригиналы | До и после сверить имена, расположение, число файлов, размер, время создания/изменения и содержимое. CI сверяет SHA-256/времена своего искусственного набора | NOT RUN |
| Заглушка архива | «Собрать архив» сообщает, что копирование/перемещение не реализованы; новых фото или архивов не появляется | NOT RUN |

Миниатюры офлайн не кешируются в 0.2.1: пустой превью-блок при отключённом источнике — известное ограничение P1.
Windows Server 2025 в CI не заменяет проверку Windows 11 и компьютера пользователя.
Прочие ограничения, включая кеш хеша по размеру/времени и обновление времени доступа самой ОС, — в BUILD_REPORT_RU.md.
