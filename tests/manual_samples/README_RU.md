# Искусственный набор для ручной проверки

Все 80 изображений созданы программно: цветные квадраты/пиксель. Пользовательских снимков нет.
Добавьте Source_A (76 BMP, включая Nested) и Source_B (4 файла): всего 80 записей, две страницы.
identical-a.bmp и identical-b.bmp — единственная точная пара. same-size-different.bmp имеет тот же размер, но другое содержимое.
capture-2020.jpg и synthetic-gps.tiff содержат искусственную EXIF-дату 08.07.2020 09:10:11.
Только synthetic-gps.tiff содержит искусственный GPS. Это тестовые координаты, не место съёмки настоящей фотографии.
У BMP нет EXIF: должна отображаться «Дата файла». Год даты файла зависит от распаковки архива.
SHA256.json позволяет разработчику сверить содержимое; для пользователя достаточно проверки свойств в Проводнике.
Набор предназначен для локального тестирования. Приложение не должно менять эти файлы.
