# Фотоархив

Локальная фотобиблиотека для Windows 11 x64, C# / .NET 10 / WPF. Оригиналы фотографий приложение читает, не перемещает и не удаляет.

Проверка Windows-сборки: [GitHub Actions](https://github.com/kqh2rnnnmm-dot/Fotoarhiv/actions).
Архив приложения появляется в Artifacts только после успешной компиляции, тестов и проверки интерфейса.

- [Инструкция по проверке без терминала](WINDOWS_CHECKLIST_RU.md)
- [Подробности и ограничения](README_RU.md)
- [Отчёт о проверках](BUILD_REPORT_RU.md)
