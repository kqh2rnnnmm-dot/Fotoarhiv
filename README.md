# Фотоархив

Локальная фотобиблиотека для Windows 11 x64, C# / .NET 10 / WPF. Приложение читает оригиналы, не перемещает и не удаляет их.

**Тестовая версия 0.2.1:** [успешная Windows-сборка и проверки](https://github.com/kqh2rnnnmm-dot/Fotoarhiv/actions/runs/41348272593).
На Windows Server 2025 прошли 18 xUnit-тестов, запуск/закрытие и 16 GUI-проверок. Проверка на ПК пользователя с Windows 11 остаётся отдельным этапом.

## Как проверить без терминала

1. [Скачайте Windows-артефакт](https://github.com/kqh2rnnnmm-dot/Fotoarhiv/actions/runs/41348272593/artifacts/13100027205), войдя в GitHub.
2. Распакуйте скачанный ZIP, затем вложенный `Fotoarhiv_Windows_x64_TEST.zip`. Все DLL и другие файлы оставьте рядом с `Fotoarhiv.exe`.
3. Дважды щёлкните `Fotoarhiv.exe`. Отдельная установка .NET не требуется.
4. Добавьте небольшую тестовую папку, проверьте поиск и раздел «Точные повторы», закройте и снова откройте программу: каталог должен сохраниться.

Искусственные тестовые изображения — в `tests/manual_samples`. Чтобы получить их вместе с исходниками, выберите **Code → Download ZIP**.
