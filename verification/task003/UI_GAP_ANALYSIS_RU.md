# Расхождения до изменений

Эталон: исходный локальный HTML и 4 приложенных PNG, 1440×900. Пользователь подтвердил именно этот дизайн.

| Область | До | Цель из HTML |
|---|---|---|
| Оболочка | Тёмное меню 212, нет отдельного топбара | Белое меню 232, белый топбар 87; фон #F6F7F9 |
| Навигация | 4 раздела, «Места съёмки» | Фотографии / Карта / Повторы / Альбомы / Источники |
| Заголовок | Все фотографии, число файлов | Фотографии, пояснение, ненавязчивый бейдж защиты |
| Показатели | Отсутствуют | 4 белые карточки с подлинными числами/явным неизвестным значением |
| Лента | Плоская сетка, подпись под превью | Месячные группы, 5/4/3 адаптивных колонок, подпись на градиенте |
| Сведения | MessageBox | Правая панель 420 с превью, подлинными полями и Escape |
| GPS | Простой список | Карточка честного ожидания карты + правая колонка реальных GPS |
| Повторы | Два списка без превью | Белые карточки групп, настоящие превью; будущие категории помечены |
| Источники | Список путей | Белые карточки доступности, имена/пути и известное число фото |
| Архив | MessageBox | Модальное окно с двумя недоступными режимами, без плана и запуска |

Точные CSS-токены: фон #F6F7F9; текст #1A2636; muted #798494; линия #E7EBF1;
акцент #3368F0; меню 232; топбар 87; контент padding 34/35; радиусы 9–22;
заголовок 29, месяцы 17, body 14; Segoe UI. Фиктивные картинки, города и числа не переносятся.
Ядро фиксируется SHA-256, менять сканер/SQLite/EXIF/GPS/SHA-256 не планируется.
Основная ОС пользователя Windows 10 x64; Server CI не заменяет Windows 10/11.
