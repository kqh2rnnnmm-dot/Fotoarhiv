# Объём P1.1

База: 766b05a из task003/ui-parity. main не используется и не изменяется.

- Core: добавлены PathIdentity и ThumbnailCache. Прежние пять файлов ядра не менялись; схема SQLite прежняя.
- App: LibraryViewState/PhotoSelection/ViewerSequence — состояние просмотра; SortPreferenceStore — только направление сортировки; ThumbnailService — штатный WPF codec adapter.
- MainWindow.P1.cs продолжает тот же MainWindow: внутренняя панель просмотра, выбор, источники и асинхронные запросы миниатюр. Существующие сканирование/EXIF/GPS/SHA и архив-заглушка сохраняются.
- Кеш: контейнер .thumb с PNG до 512 px, SHA-256 заголовка и пиксельных данных, атомарная запись только в LocalAppData. Четыре работника, очередь 128, видимая область с запасом 220 DIP. Автоматической уборки старых версий нет.
- Просмотр: один оригинал, без соседнего преддекодирования, ограничение 32 Мп / 8192 px. 100% — физические пиксели экрана; уменьшенный или офлайн-кеш не выдаётся за оригинальные 100%.
- Источники: только сеанс, объединение пересечений по границам каталогов; SQLite/хеши/кеш не удаляются, сканируются все зарегистрированные корни. Начальное состояние следующего сеанса — все видимы.
- Выделение: галочки, Ctrl/Shift, диапазон по текущему отсортированному фильтру, выбор через страницы; сброс при изменении запроса/года/источников/сортировки. Файловых массовых действий нет.

Проверки: 50 xUnit, 5 тестов упаковки, старые 31 GUI и отдельные 36 P1.1 GUI — PASS в Windows run 41487270281. Логи и измерения в windows-run2, сводка в BUILD_REPORT_RU.md. P0 принят пользователем по Task004; приёмка нового P1.1 на Windows 10/11 отдельно.
