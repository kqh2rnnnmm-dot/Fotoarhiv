Работа начата от `task003/ui-parity`, commit `766b05abe84aed356b83baecf2642e5aaa9c3f96`. Отдельная ветка — `task004/p1-1`; `main` не изменён. P0 v0.2.2 принят пользователем на Windows 10 согласно переданному Task004. Новая приёмка P1.1 на его ПК ещё не выполнена.

Существующее решение, имена проектов и базовый WPF-дизайн сохранены. Добавлены два файла ядра (`PathIdentity.cs`, `ThumbnailCache.cs`) и модели/адаптеры представления. Схема SQLite прежняя; миграция и отдельное SQL-состояние скрытия источников не вводились.

## Ограничения и непроверенное

- Новый P1.1 на Windows 10/11 пользователя ещё не принят. Windows Server CI не приравнивается к этим ОС. Редакция Windows 10 неизвестна. Стек .NET 10 сохранён; официальная поддержка Windows 10 зависит от конкретного Enterprise/IoT LTSC-выпуска, при этом пользователь сообщил о работающей базе v0.2.2 на своём ПК.
- Реальные системные DPI 125%/150%, физическое отключение USB и отдельный NTFS ACL-сценарий — NOT RUN, если не указано иначе в итоговой таблице. Имитация отсутствующего собственного каталога не является проверкой физического USB.
- Не гарантируется поддержка всех HEIC/RAW/многостраничных форматов и кодеков. Слишком большой оригинал ограничивается по разрешению; уменьшение обозначается явно.
- Нет автоматической уборки старых версий кеша, общего LRU-лимита диска и глобальной оптимизации архивов на сотни тысяч фото — это следующие этапы. Кеш растёт с просмотренными файлами/версиями.
- Размер/UTC-время/известный SHA определяют версию. Подмена содержимого с сохранением размера/времени и неизвестным/сохранённым старым SHA не гарантируется обнаруженной; инкрементальный сканер P1.3 не переписывался.
- Измерение на 1000 маленьких искусственных BMP и одном большом JPEG — проверка конкретного сценария и границ ресурсов; не обещание производительности на любой реальной библиотеке.
- Оригиналы не переписываются. Время последнего доступа может обновляться ОС при чтении; проверяются имя/путь, байты/размер, создание/запись. Логи приложения не добавляют приватных путей/GPS.

Сборка TEST и неподписанная, VBS/PS1/CMD/BAT-запускателей нет. Не обещается отсутствие SmartScreen/антивирусных предупреждений; защиту не отключать и исключения не добавлять.

## Проверка на ПК без терминала

1. Распакуйте весь Windows ZIP в отдельную папку; все DLL/подпапки оставьте рядом с `Fotoarhiv.exe`.
2. Откройте EXE. Прежний каталог v0.2.2 остаётся в LocalAppData/Fotoarhiv; не удаляйте базу для проверки.
3. На небольшом тестовом наборе проверьте галочки, сортировку, «Открыть фотографию»/Fit/100%/Esc и переключатели источников.
4. Дождитесь миниатюр, закройте приложение; на собственном искусственном USB-наборе можно проверить офлайн-превью. Не используйте приватные оригиналы для экспериментов.
5. Полная ручная приёмка — `WINDOWS_P1_1_CHECKLIST_RU.md`. После перезапуска порядок сохраняется, источники снова показаны все. Для пользователя Python/.NET SDK не нужны, runtime включён.
