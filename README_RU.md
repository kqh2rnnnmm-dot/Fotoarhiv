# Фотоархив 0.2.3 TEST — P1.1

Продолжение существующей v0.2.2 из `task003/ui-parity`. Изменения находятся в `task004/p1-1`; `main` не изменён. Основная целевая система — Windows 10 x64, также Windows 11 x64. P0 принят пользователем по заданию; новый P1.1 ещё требует проверки на его ПК.

Windows CI успешно выполнил Release-сборку (0 ошибок/предупреждений), 50 xUnit, 5 проверок упаковки, 31 прежнюю и 36 новых GUI-проверок. Фактическая ОС runner — Windows Server 2025, 10.0.26100. [Запуск и артефакты](https://github.com/kqh2rnnnmm-dot/Fotoarhiv/actions/runs/41487270281). Это не заменяет ручную приёмку P1.1 на Windows 10/11.

## Запуск без терминала

1. Скачайте [проверенную Windows-сборку](https://github.com/kqh2rnnnmm-dot/Fotoarhiv/actions/runs/41487270281/artifacts/13163031562) (для артефактов Actions нужен вход в GitHub).
2. Распакуйте внешний ZIP, затем вложенный `Fotoarhiv_Windows_x64_TEST_0_2_3.zip` в отдельную папку. Сохраните все файлы и подпапки рядом с `Fotoarhiv.exe`.
3. Запустите `Fotoarhiv.exe`. Runtime включён; .NET SDK и Python не нужны. Существующий каталог в `%LOCALAPPDATA%\Fotoarhiv\catalog.sqlite` сохраняется.
4. Проверьте небольшой набор по [ручному чек-листу P1.1](WINDOWS_P1_1_CHECKLIST_RU.md). Не удаляйте существующую базу для проверки.

## Что доступно

- Прежние сканирование подпапок, SQLite, поиск, год, EXIF/GPS, точные дубли SHA-256 и отмена сканирования.
- Постоянные миниатюры в LocalAppData/Fotoarhiv/Cache/Thumbnails. Доступны после перезапуска и без исходного диска; офлайн-состояние обозначается явно.
- В правой панели — «Открыть фотографию»: внутренний просмотр, «Вписать», «100%», прокрутка/перетаскивание, стрелки и Esc. Для очень большого снимка действует явное ограничение разрешения 32 Мп / 8192 px; уменьшенная версия не называется оригинальными 100%.
- Галочки, Ctrl/Shift, диапазон и выбор через страницы. Фильтры и порядок очищают выбор; массовых файловых операций нет.
- Сначала новые/старые; направление сохраняется после перезапуска.
- В «Источниках» — показывать/скрывать и показать/скрыть все. Только на текущий сеанс: записи, кеш и хеши сохраняются, сканирование охватывает все зарегистрированные корни. Новый запуск снова показывает все источники.

Фото открываются только для чтения. Удаление, перемещение и физическая сборка архива не реализованы. Отсутствующие диски не очищаются из каталога. Нет загрузки фото/EXIF/GPS в сеть; открытие GPS в браузере — прежнее отдельное действие пользователя.

Стек .NET 10 сохранён; редакция Windows 10 пользователя неизвестна, поддержка ОС со стороны .NET зависит от выпуска. Полный список ограничений и измерения — в отчёте. Сборка тестовая и неподписанная; защиту Windows не отключать.

Исходники: существующие проекты `src/Fotoarhiv.Core`, `src/Fotoarhiv.App`, `tests/Fotoarhiv.Tests`; CI — `.github/workflows/build-windows.yml`. Тесты нового поведения добавлены до реализации. Все прежние пять файлов ядра совпадают с базовой v0.2.2 по SHA-256, схема SQLite не менялась.
