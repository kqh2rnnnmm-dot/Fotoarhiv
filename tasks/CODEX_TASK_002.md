# CODEX_TASK_002 — «Фотоархив»: подтвердить P0 на Windows x64

**Исходная контрольная точка:** 01.11.2026, версия 0.2.1, полный исходный проект `Fotoarhiv_SOURCE_v0_2_1.zip`.

**Главная цель:** получить реально проверенную тестовую Windows x64-сборку WPF-приложения «Фотоархив», не расширяя функциональность. Linux-сборка и 18 xUnit тестов уже подтверждены в переданном отчёте; Windows-сборка, запуск окна и пользовательские сценарии ещё НЕ подтверждены.

## 1. Обязательный вход и границы

1. Распакуй исходный проект 0.2.1. Прочитай `AGENTS.md`, `BUILD_REPORT_RU.md`, `README_RU.md`, `tasks/CODEX_TASK_001.md`, текущие исходники, тесты и CI workflow.
2. **Не создавай новый проект**. Сохрани имена решения, пространств имён, классов, папок, навигацию и текущий UI. Обнови устаревшее утверждение в `AGENTS.md` о том, что нет успешных сборок: подтверждена Linux компиляция и 18 тестов, но нет подтверждения Windows.
3. Не добавляй карту внутри приложения, визуальные дубли, копирование, перемещение, удаление, новую навигацию и редизайн. Кнопка «Собрать архив» должна оставаться явно неактивной по функциональности/заглушкой.
4. Не использовать VBS, PS1, CMD как пользовательские запускатели, обход ExecutionPolicy, отключение антивируса, требования исключений SmartScreen. Допустимые CI-инструменты не включать в дистрибутив приложения.
5. Не делать `git push`, PR или публикацию от имени пользователя. GitHub через ChatGPT — только чтение; изменения возвращай ZIP. Если доступна локальная рабочая копия, изменяй только её.

## 2. Последовательность работы

**A. Подтверди исходное состояние.** Проверяй, что ZIP действительно содержит `Fotoarhiv.slnx`, проекты WPF/Core/Tests, `.github/workflows/build-windows.yml`, 18 тестов и исходные журналы. Зафиксируй состояние до изменений.

**B. Проверки на Windows.** Предпочтительно реальная Windows 11 x64. Если её нет, подготовь и проверь Windows runner GitHub Actions (владелец загрузит изменения через графический интерфейс; не заявляй выполненную проверку, пока run не состоялся). Не подменяй выполнение Windows-компиляции кросс-публикацией из Linux.

Выполни: восстановление NuGet, Release-сборку, 18+ xUnit тестов с TRX, self-contained `win-x64` publish со всеми зависимостями, запуск `Fotoarhiv.exe`, появление основного окна, создание локальной SQLite БД и штатное закрытие. Сохрани журналы и номер/URL Windows Actions run (если CI действительно запущен).

**C. Проверяй пользовательские сценарии на Windows (вручную или с подлинной GUI-автоматизацией).** Минимальный набор:
- Первый запуск при пустом каталоге, без ошибок и лишних запросов.
- Добавление двух отдельных источников, сканирование вложенных папок.
- Фильтр по году, поиск, навигация, переключение страниц и карточка снимка.
- Подлинная EXIF-дата и явно помеченная дата файла при отсутствии EXIF.
- GPS из тестового снимка; карта открывается в браузере **только после действия пользователя**, с предупреждением, что координаты передаются сервису OpenStreetMap.
- Два идентичных файла с разными именами попадают в одну группу; два разных файла одинакового размера — нет.
- Остановить сканирование без ложного сообщения об успехе.
- Повторный запуск сохраняет каталог. Отключённый внешний диск не приводит к очистке карточек; при недоступности полноразмерного файла выводится понятная пометка. В этой версии сохранение миниатюры офлайн не требуется и считается ограничением P1.
- Исходные байты, имена, местоположение, время изменения и создания снимков неизменны после сканирования/хеширования.
- Ошибка чтения не завершает всю программу и отражается пользователю.

Если не можешь физически подключить/отключить диск, пометь эту проверку **NOT RUN**, а не PASS; можно дополнить имитационным тестом, но это отдельная запись.

**D. Исправление дефектов:** только если обнаружены ошибки P0. Для каждого изменения сначала тест, который воспроизводит ошибку, затем минимальное исправление, затем полный набор тестов и сборка. Никакого скрытого отключения проверок, изменения ожидаемых результатов ради зелёного статуса или частичного успеха.

**E. Доставка:** Windows ZIP из **всей** папки publish, а не один exe. Включи все нужные SQLite/runtime DLL. Не называй неподписанную или непротестированную сборку безопасным релизом.

## 3. Известные риски для проверки

- `tests/windows_smoke.py` проверяет старт, SQLite и завершение, но НЕ сканирование, поиск и галерею. Не считать один smoke-тест ручной проверкой UX.
- GitHub `windows-latest` может быть не Windows 11; отчёт должен содержать фактическую ОС.
- Отображение до 72 миниатюр сейчас выполняется синхронно и может задерживать GUI; не проводить оптимизацию P1 без обнаруженного блокирующего дефекта P0.
- Каталог сохраняет карточки недоступных источников, но миниатюры в v0.2.1 не кешируются локально. Не выдавай эту возможность за уже реализованную.
- Возможны предупреждения SmartScreen для неподписанного exe. Не обходить защиту и не обещать, что предупреждений не будет.

## 4. Критерии завершения P0

P0 можно назвать **технически проверенным на Windows** только если есть логи Windows Release build, тестов и publish, подтверждение запуска/закрытия программы и отчёт о фактически выполненных основных сценариях. Проверку именно на компьютере пользователя отмечай отдельно. Если какого-либо этапа нет — P0 остаётся открытым.

## 5. Формат результата для пользователя

Передай:

1. `Fotoarhiv_SOURCE_v0_2_2.zip` — полный актуальный исходный проект, включая инструкции, тесты, workflow и отчёты; если исходники не менялись, честно оставь версию 0.2.1, без искусственной смены номера.
2. `Fotoarhiv_Windows_x64_TEST.zip` — **только при реально успешной Windows-сборке и проверке запуска**. Архивировать publish целиком.
3. `BUILD_REPORT_RU.md` — таблица `проверка / PASS, FAIL, NOT RUN / среда / доказательство`; фактическая ОС, номер/ссылка CI run, результаты xUnit, список изменений и известных ограничений.
4. `WINDOWS_CHECKLIST_RU.md` — инструкция на русском, как распаковать, открыть и проверить приложение на Windows 11 **двойным щелчком, без терминала**. Никаких требований отключить антивирус.
5. Короткое резюме: **написано / скомпилировано / протестировано на Windows CI / вручную проверено на Windows / проверено пользователем**. Неподтверждённое не отмечай успехом.
