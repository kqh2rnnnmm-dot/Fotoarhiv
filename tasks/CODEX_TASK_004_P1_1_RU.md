## 1. Цель и неизменные границы

Добавить в существующее приложение пять взаимосвязанных возможностей **P1.1**:
1. постоянный **локальный кеш миниатюр**, доступный, в том числе, когда источник отключён;
2. **полноразмерный просмотр** открываемого фото внутри приложения;
3. **множественное выделение** фотографий в галерее;
4. переключение сортировки **«Сначала новые» / «Сначала старые»**;
5. временное **включение/скрытие источников для текущего просмотра**, без исключения их из каталога.

Не начинать следующие этапы: P1.2 (глобальная переработка производительности), P1.3 (полный пересмотр инкрементального сканирования), P2 (поиск похожих/версий), P3 (встроенная карта), P4/P5 (копирование и перемещение файлов). Не менять название, структуру исходников, существующие публичные пользовательские надписи без необходимости. Сохранять **утверждённый светлый WPF-дизайн** v0.2.2; первичный визуальный эталон — `UI_REFERENCE/Фотоархив — прототип.html` и четыре PNG рядом. Новые элементы должны быть деликатным продолжением этой системы, без нового редизайна.

**Безопасность без исключений:** исходные фотографии открываются только на чтение; никакого изменения EXIF/времени записи, переименования, удаления, перемещения, физического копирования архива. Разрешены записи только в локальный каталог приложения (SQLite, кеш миниатюр, настройки, журнал без приватных путей/GPS). Не загружать фото, миниатюры, пути или GPS в сеть. Не создавать VBS/PS1/CMD/BAT-запускатели, не обходить SmartScreen/антивирус.

## 2. Постоянные миниатюры (основной пункт P1.1)

- Хранить уменьшенные изображения **только** под `%LOCALAPPDATA%\Fotoarhiv\` (например, `Cache\Thumbnails`); не создавать `.thumbs`, базы или служебные файлы рядом с исходниками. Сканирование и вывод миниатюр не должны изменять исходные фотографии.
- Ключ кеша должен устойчиво идентифицировать исходный путь и версию файла (как минимум нормализованный путь, размер, UTC-время изменения; хеш ключа в имени кеша, чтобы избежать коллизий/раскрытия полного пути через имена). Метаданные кеша могут храниться в приложении/SQLite. Защититься от неверной миниатюры после изменения файла, совпадения имён, переименования, повторного сканирования и повреждения кеша.
- Генерировать миниатюры **по запросу для видимых карточек и разумной очереди**, не декодировать десятки тысяч оригиналов сразу. Ограничить параллелизм, память, длину очереди и уметь отменять ненужную загрузку при смене страницы/источников/сортировки и закрытии окна. Не блокировать UI на I/O, декодировании или записи кеша.
- При повторном открытии, когда источник доступен и не изменён, использовать готовую миниатюру. Если внешний диск отключён — показывать **последнюю сохранённую миниатюру** с честным индикатором «Источник недоступен». Не выдавать кеш за полноразмерный оригинал. Если кеша нет или формат не поддержан — аккуратная заглушка, но запись фото остаётся в каталоге.
- При обнаруженном изменении содержимого/версии файла устаревший кеш не выдавать за актуальный: перегенерация; при ошибках чтения/записи показать неразрушающую заглушку, не падать и не удалять записи. При неизвестном состоянии недоступного источника допустима последняя миниатюра с явной пометкой.
- Управление кешем, включая возможную очистку, касается **только собственных файлов приложения**. Без фоновой уборки файлов исходных папок; не вводить рискованную очистку пользовательской фотоколлекции.
- Повторно использовать миниатюры в фотоленте, разделе повторов, списке GPS и полноразмерном просмотре как временную заглушку при загрузке оригинала. Поддержку HEIC/RAW не объявлять гарантированной без кодеков/тестов.

## 3. Полноразмерный просмотр фотографии

- Сейчас одиночный клик открывает **правую панель сведений**; сохранить этот сценарий или сделать его равноценным по минимальному числу действий. Добавить в карточку и/или на фото явное действие **«Открыть» / развёрнуть**, которое открывает крупный просмотр **внутри окна приложения**. Не запускать внешний просмотрщик по умолчанию.
- По умолчанию режим **«Вписать в окно»** с сохранением пропорций; отдельный переключатель **«100%»** для просмотра в исходных пикселях, прокрутка/перетаскивание при увеличении, удобное возвращение к «Вписать». Не растягивать маленькое изображение так, чтобы оно казалось изображением большего качества; при нехватке памяти не загружать все соседние оригиналы заранее.
- Кнопки «Предыдущее»/«Следующее» и стрелки клавиатуры листают **текущую отфильтрованную и отсортированную последовательность**, а не весь каталог. Esc закрывает просмотр; фокус возвращается на ранее выбранный снимок. Информация о снимке/дате/источнике доступна без обязательного отдельного окна.
- Если источник недоступен: полноразмерный оригинал недоступен, допустимо показать кешированную миниатюру, **явно указав «Только миниатюра, источник недоступен»**. Не показывать кеш как полноразмерный файл. Для неподдерживаемого формата — понятная заглушка без аварии.
- Открытие изображения не изменяет оригинал и не открывает непрошенные сетевые адреса. Если для P1.1 нельзя безопасно поддержать очень большие изображения целиком, использовать ограниченный декодер и честно указать ограничения, сохранив режим просмотра.

## 4. Множественное выделение фотографий

- На каждой плитке добавить неброский чекбокс выделения в духе HTML-эталона: **один клик по чекбоксу — добавить/снять выделение**, клик по самой фотографии — открыть сведения или полный просмотр, без конфликта действий. Дополнительно поддержать Ctrl+клик и Shift+клик как привычное поведение Windows, где это устойчиво реализуемо.
- Видимое состояние выделения (рамка/галочка), счётчик **«Выбрано: N»** и действие **«Снять выделение»**. Предусмотреть выбор на разных страницах текущего фильтра, но при изменении включённых источников, поискового запроса или сортировки **очищать выделение с понятным визуальным результатом**, чтобы не было скрытого набора. Никаких массовых действий по файлам в P1.1.
- Выделение в P1.1 — **локальное состояние интерфейса**, без изменения SQLite-данных фотографий и без операций удаления/перемещения. Это основа для будущих сценариев сравнения и сбора архива, но сейчас не показывать активные кнопки несуществующих действий.
- Учитывать недоступные источники: карточка может быть выделена (метаданные существуют), но действия требующие оригинала недоступны или объясняют причину.

## 5. Сортировка «Сначала новые / Сначала старые»

- В верхней части фотоленты рядом с фильтром года добавить компактный понятный переключатель. По умолчанию **«Сначала новые»**, как сейчас. У пользователя должен быть выбор «Сначала старые».
- Сортировать по установленной дате съёмки (EXIF, когда есть; помеченный fallback «Дата файла»), **не по времени импорта**. Переключатель меняет порядок и **месячных групп**, и снимков внутри групп, включая порядок при открытии/листании полноразмерного просмотра и переходе между страницами. Для одинаковых дат обеспечить детерминированный второй ключ (путь/ID), чтобы снимки не дублировались/пропадали при переключении.
- Предпочтение сортировки разрешается хранить в **настройках приложения**, но не в исходных папках и не в EXIF. После перезапуска сохранять выбранное направление; не менять данных фотографии.
- Сортировка должна корректно сочетаться с поиском, фильтром года, включёнными источниками и постраничным просмотром.

## 6. Показывать / скрывать источники ТОЛЬКО для текущего просмотра

- В разделе **«Источники»** (желательно также быстро доступно из фотоленты) добавить переключатель **«Показывать в библиотеке»** возле каждой ранее добавленной папки/диска, плюс «Показать все» и «Скрыть все». Начальное состояние: **все источники показываются**.
- При скрытии источник **остаётся зарегистрированным в SQLite** и физически на диске. Ни одна его фотография, точный дубль, GPS, SHA-256 или миниатюра не удаляются из каталога/кеша. При включении обратно карточки возвращаются **мгновенно без нового сканирования**.
- Фильтр относится **только к отображению в интерфейсе**: фотолента, поиск, год, GPS-списки/показатели и группы точных дублей должны показывать релевантное подмножество. Если группа дублей после фильтрации содержит менее двух видимых экземпляров, не показывать её как текущую группу точных повторов. Глобальные записи и ранее вычисленные хеши остаются нетронутыми.
- Прозрачно различать числа: «В каталоге: N / Показано: M» или другой лаконичный вариант. Если отключены все источники, показать понятную пустую библиотеку **без предложения повторно импортировать/удалять фотографии**.
- Переключатели действуют **на текущий сеанс/просмотр**; по умолчанию после нового запуска все источники видимы. Не создавать отдельное постоянное состояние удаления/деактивации источника. Если будут реализованы сохранённые настройки видимости, это потребует отдельного согласования — в рамках этой задачи не делать.
- Вложенные/пересекающиеся источники: фотография считается видимой, если её путь принадлежит **хотя бы одному включённому источнику**. Один снимок не должен отображаться дважды, если его папки пересекаются. Вычисление принадлежности по границе каталогов, а не по простому префиксу (`C:\Photos` не включает `C:\PhotosOld`). UNC/регистр/концевые разделители обрабатывать корректно.
- Скрытие источника не должно автоматически исключать его из **сканирования** и обновления каталога: это только фильтр просмотра, не управление импортом. Не переписывать сканер. Отображать доступность диска отдельно от переключателя видимости.

## 7. Требования к UX и совместимости

- **Сохранять визуальный язык v0.2.2**: светлая боковая панель, топбар, карточки, фотографии с градиентами, мини-панель сведений. Не создавать второй дизайн, новые громоздкие окна или длинный мастер настроек. Один сценарий — минимум кликов.
- Новые переключатели располагаются рядом с контекстом действия. Не перегружать главный экран техническими полями. Управление клавиатурой (Tab/Enter/Escape; Ctrl/Shift где применимо), доступные подписи и видимый фокус.
- Контроль размеров: 1366×768, 1440×900, 1920×1080; масштаб 100%, 125%, 150%. Боковые панели/окно просмотра и кнопки не перекрывают друг друга.
- **Основной компьютер пользователя — Windows 10 x64**; также Windows 11 x64. Тест Windows Server 2025 не доказывает автоматически совместимость Windows 10. При необходимости документировать поддержку .NET 10/допуски конкретной редакции, но не менять стек по умолчанию.
- Пока пользователь не подключил источники — честная пустая библиотека без демонстрационных фотографий/цифр. При отключённом диске ничего не вычищать.
