# Как передать проект Codex — без GitHub-записи и терминала

1. Скачайте `Fotoarhiv_Codex_Handoff_v0_2.zip` и сохраните его на компьютере. Внутри весь исходный проект и правила разработки. Старый ZIP с VBS/PowerShell не используйте.
2. Откройте Codex. Если он позволяет прикреплять ZIP — приложите этот файл; если работает с папкой на компьютере — распакуйте ZIP и выберите полученную папку с `Fotoarhiv.slnx`. Подключать GitHub с правами записи не требуется для работы с локальной копией.
3. Откройте `tasks/CODEX_TASK_001.md`, скопируйте его текст в задание Codex (либо дайте Codex ссылку на файл в открытом проекте). `AGENTS.md` лежит в корне и предназначен для автоматического чтения Codex.
4. Попросите Codex в конце предоставить ZIP исходного проекта, отчёт о тестах и ZIP Windows x64 сборки, только если она действительно собрана и прошла проверки.
5. Для продолжения в этом чате приложите полученный ZIP и отчёт. Не требуется, чтобы ChatGPT записывал что-то в GitHub: версии можно передавать архивами. Если позже понадобится публикация в GitHub, её можно выполнить самостоятельно через GitHub Desktop (кнопки Commit / Push), без командной строки.

Важно: права на GitHub в основном чате и доступ Codex к своей локальной копии — разные вещи. Наличие подключённого GitHub с режимом «только чтение» не гарантирует ни права записи в Codex, ни автоматическую публикацию.
